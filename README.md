# Paraveda CRM — النسخة الاحترافية v2.0

نظام احترافي كامل لإدارة طلبات **الدفع عند الاستلام (COD)** — من التأكيد حتى التوصيل،
مع حساب أوتوماتيكي للأجور والأرباح، تحليل المدن، تتبع الإعلانات، وسجل كامل لكل العمليات.

> هذه نسخة معاد بناؤها من الصفر للنسخة القديمة (index.html + api.php) بمعمارية حديثة ونظيفة،
> **وتستورد بياناتك القديمة كاملة** (`crm_data.json`) بضغطة زر.

---

## ✨ الميزات

| الصفحة | الوصف |
|---|---|
| 🔐 **الدخول والصلاحيات** | حسابات آمنة (PBKDF2 + رموز موقّعة HMAC) — المديرون يشوفون كلشي، وكل مسؤولة تشوف غير طلبياتها |
| 📊 **لوحة القيادة** | مؤشرات KPI مع مقارنة بالفترة السابقة + رسوم بيانية (تطور الطلبيات، توزيع الحالات، أفضل المنتوجات، أعلى المدن) |
| 🛒 **الطلبيات** | إضافة/تعديل/حذف، بحث وفلاتر (حالة، توصيل، منتوج، مسؤولة، مصدر، فترة)، ثمن التوصيل أوتوماتيكي حسب المدينة، تصدير CSV، الطلبية الملغاة بخط أحمر |
| 🚚 **التوصيل** | لوحة متابعة الشحنات: مسلّمة / في الطريق / مرتجعة / نفاد المخزون + تغيير الحالة مباشرة — المرتجع = 0 DH |
| 📦 **المنتوجات** | الكتالوج (ثمن البيع، العمولة، ثمن الشراء، المخزون) + أداء كل منتوج وصافي ربحه |
| 🏙️ **المدن** | 515 مدينة مع ثمن التوصيل — تعديل مباشر + إحصائيات لكل مدينة |
| 📣 **الإعلانات** | مصاريف الإعلان لكل منتوج/مصدر + ROAS + صافي الربح الحقيقي |
| 💵 **الأجور** | حساب أوتوماتيكي: `المسلّمة × 8 + UPSEL(المسلّمة فقط) × 8 + بونص 1000 DH عند 151 تسليم` — المعدلات قابلة للتعديل |
| 👥 **الفريق** | إنشاء الحسابات، الأدوار، التوقيف، إحصائيات كل مسؤولة، آخر نشاط |
| 🕘 **السجل** | كل عملية (إضافة/تعديل/حذف/استيراد) مسجلة بالمستخدم والوقت — للإدمنز فقط |
| ⚙️ **الإعدادات** | معدلات الأجور، مصادر الطلبيات، نسخ احتياطية JSON، استعادة، واستيراد بيانات النسخة القديمة |

**صافي الربح** = مبيعات المسلّم − ثمن الشراء − العمولات − رسوم التوصيل (حسب مدينة الزبون) − مصاريف الإعلان.

## 🧰 التقنيات

- **الواجهة:** React 18 + TypeScript + Vite + Tailwind CSS 4 + Recharts — واجهة RTL عربية بخط Cairo
- **الخادم:** اختيارك:
  - **Node.js** (Express) — `server/index.js`
  - **PHP** — `api.php` (للاستضافة العادية cPanel بدون Node)
- **التخزين:** ملف `data/db.json` (نفس الصيغة في النسختين) + نسخ احتياطية دوّارة في `data/backups/`
- الواجهة تكتشف الخادم أوتوماتيكياً (`/api` أو `api.php`) — نفس البناء يخدم على النسختين.

## 🚀 التشغيل

### تطوير (Dev)
```bash
npm install
npm run server      # خادم API على المنفذ 8787
npm run dev         # واجهة التطوير على المنفذ 5173 (متصل بالخادم تلقائياً)
```

### إنتاج على Node
```bash
npm run build       # يبني الواجهة في public_html/
npm start           # يبني ويشغل كل شيء على المنفذ 8787
```

### النشر على استضافة cPanel / PHP
1. ارفع محتويات مجلد **`public_html/`** (الواجهة المبنية) + ملف **`api.php`** + مجلد **`server/import.php`**
2. تأكد أن مجلد **`data/`** موجود وقابل للكتابة (الصلاحيات 755 أو 775)
3. افتح الرابط — سيسجل الدخول المدير ببيانات النسخة القديمة نفسها

> ملاحظة: مجلد `server/` مطلوب لملف `import.php` فقط (استيراد النسخة القديمة من صفحة الإعدادات).

## 🔑 أول دخول

- **إذا استوردت بيانات النسخة القديمة** (أوتوماتيكياً عند وجود `data/legacy-crm_data.json` أو من صفحة الإعدادات):
  جميع الحسابات القديمة تعمل بنفس أسماء المستخدمين وكلمات السر (مثل `admin@paraveda.ma` و `imane`).
- **قاعدة بيانات جديدة:** `admin@paraveda.ma` / `paraveda2026` — **غيّرها فوراً من صفحة الفريق**.

## 📥 استيراد النسخة القديمة

من **الإعدادات ← استيراد بيانات النسخة القديمة**: ارفع ملف `crm_data.json` وسيتحوّل تلقائياً:
الطلبيات، الكتالوج، المدن وأثمنة التوصيل، الحسابات (كلمات السر تبقى كما هي)، مصاريف الإعلان، والسجل.

## 🔌 نقاط النهاية (API)

| الطريقة | المسار | الوصف |
|---|---|---|
| `POST` | `/api/login` | تسجيل الدخول → رمز جلسة |
| `GET` | `/api/bootstrap` | كل بيانات النظام (مقيدة حسب الصلاحية) |
| `POST/PUT/DELETE` | `/api/orders[/:id]` | إدارة الطلبيات |
| `POST/PUT/DELETE` | `/api/products[/:id]` | الكتالوج (مدير) |
| `PUT` | `/api/cities` | تحديث أثمنة التوصيل (مدير) |
| `POST/PUT/DELETE` | `/api/adspend[/:id]` | مصاريف الإعلان (مدير) |
| `POST/PUT/DELETE` | `/api/users[/:id]` | الحسابات (مدير) |
| `PUT` | `/api/settings` | الإعدادات ومعدلات الأجور (مدير) |
| `GET` | `/api/export` · `POST /api/restore` | نسخ احتياطي واستعادة (مدير) |
| `POST` | `/api/import` | استيراد `crm_data.json` القديم (مدير) |

في استضافة PHP نفس المسارات عبر `api.php?api=...`.

## 🔒 ملاحظات أمنية

- كلمات السر معمّاة **PBKDF2-SHA256** (100 ألف تكرار) — كلمات سر النسخة القديمة (نص صريح) تُعمّى عند الاستيراد.
- الجلسات عبر رموز موقّعة HMAC-SHA256 صالحة 30 يوماً، كلمات السر لا تُرسل أبعد من طلب الدخول.
- فحص الصلاحيات في الخادم (ليس فقط في الواجهة): كل مسؤولة تقرأ/تعدّل طلبياتها فقط، والعمليات الحساسة للمدير فقط.
- على استضافة PHP: احمِ مجلد `data/` (أو ضعه خارج المجلد العام إذا أمكن).
